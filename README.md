# alking.tech — Smart Learning Difficulties Prompt

صفحة HTML جاهزة للنشر باستخدام GitHub Pages.

## النشر

1. أنشئ Repository جديدًا في GitHub.
2. ارفع `index.html` إلى جذر المستودع.
3. من **Settings → Pages** اختر:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
4. احفظ الإعدادات وانتظر اكتمال النشر.

سيصبح الرابط عادةً:
`https://USERNAME.github.io/REPOSITORY/`

إذا كان اسم المستودع `alking-tech` مثلًا:
`https://USERNAME.github.io/alking-tech/`
